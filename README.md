# Optimization games

Index of browser games that recast operations research problems as games, served at
<https://martincousi.github.io/games/>. Linked from the main site (research themes, "Play the games") and open to search engines. Every game page links back to the main site and to this list.

Interface conventions shared by all games (layout, names, replay bar, keys, colours): `CONVENTIONS.md`.

To add a game, append an entry to the `GAMES` array in `index.html` (title, problem, one-sentence
description, URL, and a few rectangles for the thumbnail).
